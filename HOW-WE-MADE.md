# How We Made It

1. **Brand idea** — Created a dummy brand, **NOOLAM · Kanchipuram Silk**, with a divine, historic heritage-showroom feel (deep maroon, temple gold, ivory white).
2. **References** — Collected reference videos and sites for each section and kept only the interaction idea, then gave it our own saree-store twist.
3. **Prompting section by section** — Wrote one plain-sentence prompt per section (see the README) and built the page one section at a time with Claude Code.
4. **House style** — Fixed one font, button style and pure-white light sections so every section feels like the same store.
5. **Images** — Used AI-generated studio images for products and the rack, and public / open-source images for lifestyle photos.
6. **Interactions** — Added motion: drag carousels, tilting cards, hangers that lift off the rail, 3D reel arc, and a scrolling gold ticker.
7. **Check & polish** — Took screenshots of every section, compared with the references, and refined spacing, colour and motion until it felt right.

**Tools:** Claude Code, Next.js, AI image generation, open-source image libraries.
